# Retail Customer Segmentation

## Project Overview

This project focuses on customer segmentation using machine learning techniques to identify distinct customer groups based on purchasing behavior. The objective was to help businesses better understand customer patterns and support targeted marketing strategies.

## Dataset

* Mall Customers Dataset
* Customer demographic and spending behavior data

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib

## Methodology

* Data Cleaning and Preprocessing
* Exploratory Data Analysis (EDA)
* K-Means Clustering
* Principal Component Analysis (PCA)
* Elbow Method
* Silhouette Score Analysis

## Results

* Identified 4 distinct customer segments
* Determined optimal clusters using Elbow Method and Silhouette Score
* Visualized customer groups using PCA
* Generated insights for customer targeting and marketing strategies

## Project Outcome

The project demonstrates how unsupervised machine learning can be used to discover meaningful customer segments and support data-driven business decision-making.
